# GlowVeda website

A responsive, single-page brand website concept built from the supplied GlowVeda venture presentation.

## Run locally
1. Extract the ZIP (if needed).
2. Open `index.html` in a browser.
3. For a local development server, open this folder in VS Code and use Live Server, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design system, product mockups, hover and scroll effects
- `script.js` — mobile navigation, scroll reveal, demo newsletter interaction
- `assets/` — product and community visuals cropped from the supplied venture PDF

## Design inspiration
The site takes broad, non-copying inspiration from:
- [CeraVe](https://www.cerave.com/skincare): clear product/category organisation and accessible skincare education.
- [The Ordinary](https://theordinary.com/en-in/category/skincare): ingredient clarity and a simple, step-based way to think about routines.
- [Mamaearth](https://mamaearth.in/): nature-forward visual language and approachable Indian skincare positioning.

GlowVeda uses its own warm-paper, botanical-green and terracotta palette, editorial typography, custom CSS product illustrations and a youth-focused tone.

## Important launch notes
The cleanser, moisturiser and lip-care cards are concept representations of categories mentioned in the venture presentation, not confirmed products. Product visuals, final names, formulas, ingredients, pricing, efficacy claims, certifications, shipping, payments and contact details need to be confirmed before a commercial launch. The newsletter form is a front-end demo and does not store or send email addresses; connect it to an email platform before launch.
